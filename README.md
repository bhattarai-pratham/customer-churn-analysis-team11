# Customer Churn Analysis - Team 11

ACS WIL Data Analytics internship project. Stage 2 deliverable repository (LMS assignment S2W8A2), covering data preparation and clustering analysis for a telecommunications customer churn dataset (7,043 rows, 26.5% churn rate).

## Structure

- `Data_Preparation/` - preprocessed dataset file, train/test split files and documentation, scaling technique writeup with code snippets.
- `Clustering_Analysis/` - optimal-cluster (elbow method) documentation and visualisations, trained K-Means model file and code, cluster visualisation with labels and insights.

## Stack

Python, Pandas, NumPy, matplotlib, Scikit-learn.
